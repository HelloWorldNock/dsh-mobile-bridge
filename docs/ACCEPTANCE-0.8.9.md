## 2. 判定

- 全过 → 该矩阵标记 **L4 已真机**，写进 `README.md` 的验收口径表，并把 0.8.9 从「待验收」改成「已真机」。
- A14 / A15 失败 → 优先看三点：`session.removed` 是否带 `archived: true`（host `lib/events.js`）、`/api/workspaces` 是否返回 `archivedSessionIds`、手机 runtime 的 `archivedSessionIds` 是否在 `session.added` 后被清掉。
- A11 / A12 失败 → 看 `lib/endpoints.js` 的地址分类和 `bridge.go` 里写死的 `192.168.1.100`（见整改路线 §6 未验证项）。
