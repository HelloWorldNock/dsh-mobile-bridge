## 想让我把剩下的也自动跑完？

打开手机的 **设置 → 开发者选项 → 无线调试**，把「IP:端口」和**配对码**发我。之后我可以：

1. `adb pair` / `adb connect` 连上（无线调试，不用数据线）；
2. 直接安装 `dist/TS7-DSH-Remote-0.9.18-arm64-v8a-debug.apk`；
3. 用 `adb shell input` + `uiautomator dump` 逐项点按，并把截图与界面层级存进 `docs/evidence/`，
   这样 A9/A10/A11/A12/A15/A19 都能留下可复核的证据，而不是「我点了，好像没问题」。
